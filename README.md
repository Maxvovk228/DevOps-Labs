# DevOps — лабораторні роботи

Дисципліна: Розгортання інформаційно-комунікаційних систем.

## Лабораторна №1 — Vagrant і VirtualBox
Створено віртуальну машину Ubuntu 18.04 за допомогою Vagrant.
Перевірено запуск, стан VM та SSH-підключення.

## Лабораторна №2 — Docker
Встановлено Docker Engine в Ubuntu 24.04.
Запущено тестовий контейнер hello-world та вебсервер Nginx.
Перевірено роботу контейнерів, мереж і томів.

## Лабораторна №3 — Dockerfile
Створено власний образ Nginx з HTML-сторінкою.
Розроблено та контейнеризовано Flask і Node.js застосунки.
Виконано версіонування образів та публікацію Node.js у Docker Hub.
