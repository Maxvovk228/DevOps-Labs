# Лабораторна №3 — Dockerfile та власні образи

**Мета:** створення власних Docker-образів та керування їх версіями.

## Виконання
1. Створено власний Nginx-образ з HTML-сторінкою.
2. Створено Flask-застосунок на Python.
3. Створено Node.js-застосунок з Express.
4. Підготовлено Dockerfile для кожного застосунку.
5. Виконано збірку та запуск контейнерів.
6. Перевірено роботу HTTP-запитами.
7. Досліджено версіонування Docker-образів.
8. Опубліковано образ Node.js у Docker Hub.

## Структура
- `nginx/` — Dockerfile та index.html.
- `flask/` — Dockerfile, app.py, requirements.txt.
- `node/` — Dockerfile, server.js, package.json.
