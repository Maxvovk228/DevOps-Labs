# Лабораторна №1 — Vagrant та VirtualBox

**Мета:** автоматизоване створення та керування віртуальними машинами.

## Виконання
1. Встановлено Vagrant 2.4.9 та Oracle VirtualBox.
2. Створено Vagrantfile на основі Ubuntu 18.04.
3. Налаштовано 2048 MB RAM та 2 CPU.
4. Запущено VM командою `vagrant up --provider=virtualbox`.
5. Перевірено стан через `vagrant status`.
6. Виконано SSH-підключення командою `vagrant ssh`.

## Основні команди
- `vagrant up` — запуск VM.
- `vagrant ssh` — підключення до Ubuntu.
- `vagrant status` — перевірка стану.
- `vagrant halt` — зупинка VM.
- `vagrant destroy` — видалення VM.

## Результат
Успішно створено віртуальну машину Ubuntu та перевірено SSH-доступ.

**Примітка:** самостійне завдання з двома різними дистрибутивами ще не реалізовано.
